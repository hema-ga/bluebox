# FoodFlow Complete Website
Multi-page food business website with Home, Menu, Cart/Checkout, Offers, About, Contact and Business/Revenue pages.

### How the flow works
Menu → Add food → Cart → Place Order → Business page.

Completed orders are stored in browser localStorage. Revenue, order count, average order and item count update automatically.

This is a front-end demo. The data is not shared between different devices/browsers. A real multi-user system would need a backend/database.
